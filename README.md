# iPeptides

Веб-сайт о пептидах и здоровье.

## Структура проекта

```
iPeptides/
├── index.html      # Главная страница
├── css/
│   └── style.css   # Стили
├── js/
│   └── main.js     # JavaScript
└── README.md       # Документация
```

## Запуск

Откройте `index.html` в браузере или используйте локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve
```
